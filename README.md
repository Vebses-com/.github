# `.github` — organisation defaults for Vebses.com

GitHub applies the files in this repository to every repository in the organisation that does not define its own copy. Keep it public: GitHub requires that for default community files.

| Path | Used for |
| --- | --- |
| `profile/README.md` | The organisation profile shown at <https://github.com/Vebses-com> |
| `SECURITY.md` | How to report a vulnerability |
| `CONTRIBUTING.md` | How we work: branches, commits, pull requests, secrets |
| `.github/ISSUE_TEMPLATE/` | Bug report and feature request forms |
| `.github/PULL_REQUEST_TEMPLATE.md` | Pull request checklist |
| `workflow-templates/` | "Node CI" and "Secret scan" starter workflows offered in every repository's Actions tab |
| `templates/dependabot.yml` | Copy into a repository as `.github/dependabot.yml` for weekly dependency updates |

Change these files through a pull request like any other repository.
