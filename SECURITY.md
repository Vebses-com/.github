# Security policy

Most of our repositories are private client projects. If you find a security problem in anything we publish or run, please tell us privately.

**Preferred:** open the repository's **Security** tab and use **Report a vulnerability** (private vulnerability reporting).

**Otherwise:** contact us through <https://vebses.com>.

Please do not open a public issue for security problems. We aim to acknowledge a report within three working days and to keep you informed while we fix it.

**Supported versions:** the default branch of each repository, which is what is deployed.
